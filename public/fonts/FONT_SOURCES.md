# The Clinic fonts

Fonts are self-hosted through `next/font/local`. The original font binaries are
unchanged; their SIL Open Font Licenses are in `licenses/`.

- [DM Serif Display](https://github.com/google/fonts/tree/main/ofl/dmserifdisplay): English marketing headings, regular 400.
- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope): existing English UI font, variable 200–800.
- [Alexandria](https://github.com/google/fonts/tree/main/ofl/alexandria): Arabic headings, variable font used at 600–700.
- [IBM Plex Sans Arabic](https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic): Arabic body and UI, medium 500 and semibold 600.

New font files and their licenses were obtained from the Google Fonts repository
on 2026-10-05.
